## 🚀 Como Visualizar o Painel Interativo

O protótipo interativo `kudiba-dashboard.html` não requer nenhum servidor em execução nem dependências do Node.js:

1. **Via Navegador Local:**
   Abra diretamente o ficheiro no Google Chrome, Firefox ou Edge:
   ```bash
   google-chrome Frontend/docs/kudiba-dashboard.html
   # ou
   firefox Frontend/docs/kudiba-dashboard.html
   ```
2. **Cópia no Ambiente de Trabalho:**
   Uma cópia direta foi também colocada na sua pasta pessoal em:
   * `/home/jaime.coxi@hssa.local/Documentos/kudiba-dashboard.html`
